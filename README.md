### v0.50 プチリリ連携
- 歌詞検索ソフト『プチリリ』との連携機能を追加。
- 特徴
　☆歌詞検索サイトプチリリ http://petitlyrics.com/ から歌詞を取得して表示します。
　　曲のカバー範囲がとても広いです。よほどマニアックな曲でない限り対応しています。
　☆参加者は、id3タグが設定されたmp3ファイルを持込するだけで、カラオケで歌えるようになります。
　　この場合、歌詞タグファイル(txt)は不要です。
　☆従来のmp3歌詞表示機能と同様に、もちからWebの背景動画を選択して表示します。
　☆この機能は、歌詞タグファイル(txt)がないmp3ファイルが選択された場合のみ呼び出されます。
　　従来のmp4等動画表示機能、mp3歌詞表示機能は(もちろん)そのまま使用できます。

- 前提条件 (めんどくさい点など)
　☆非常に実験的です。悪しからず。
　☆インターネット接続必須。
　　運営者はスマホか何かで再生用ノートＰＣ上でテザリングができるようにしておいて下さい。
　☆専用アプリ『プチリリ PC版』で歌詞を表示します。MPC-HCの字幕表示機能では歌詞を表示できません。
　　著作権の関係で歌詞タグのダウンロードはできないようになっています。
　☆『プチリリ PC版』は行単位の切り替え表示しか対応してないです。
　　(スマホ版のプチリリアプリは文字単位の切り替えに対応しているのに……)
　☆『プチリリ PC版』はアプリとしてmp3のプレイヤーを内蔵しておらず、かつMPC-HCに対応していないため、
　　Windows Media Player 11 使用して音楽を再生します。
　　(プチリリ PC版はWindows Media Playerのプラグインとして登録されます)
　　運営者は時折勝手に起動したり終了したりするWMPを最小化したり終了させたりしてはいけません。
　☆mp3のid3タグを元に検索するので、mp4ファイルなどの動画ではプチリリ連携はできません。
　☆なるべくならこんな機能を使わずに歌詞タグファイル(txt)とセットで持ってきていただいた方が良いです(全否定)

- 連携の条件はこんな感じ
　※『プチリリ PC版』がインストールされていて、もちからWebでmp3ファイルを選択した場合
　①同名のtxtファイルがある場合　→(従来どおり)mp3＋背景動画表示
　②同名のtxtファイルがない、かつmp3のid3タグ(曲名、アーティスト名)がある場合　→プチリリ連携
　③同名のtxtファイルがない、かつmp3のid3タグ(曲名、アーティスト名)がない場合　→エラー

- 『プチリリ PC版』がインストールされていない場合、(従来どおり)同名のtxtファイルがなければエラーとします。
　(つまり、インストールされていなければ、連携機能が無効化された状態でそれなりに動作します)

- 登録済みリストには、先頭に“『プチリリ』”と記述されます

- MPC-HCのプレイリスト上、プチリリ連携する曲の前と後ろに、再生制御のためのダミー動画が自動的に追加されます。
　こんな感じ。
　①　【↓】曲名.mp4　　……Windows Media Playerとプチリリを起動する間、表示されるダミー動画です。
　②　曲名.mp4　　　　　……プチリリ連携している間、表示される背景動画です。
　③　【↑】曲名.mp4　　……Windows Media Playerとプチリリを終了する間、表示されるダミー動画です。

- プレイリストの再生順を変更する場合、上記①～③を１セットにして順番を入れ替えて下さい。
　たとえば①と②の間に別の曲を入れてしまった場合、２曲が同時に流れる惨劇が発生しますので注意下さい。

- インターネットに通信に行くのは、プチリリ連携をする曲の再生開始時だけです。
　それ以外は、インターネット接続を切断していても問題ありません。

- プチリリ連携の曲再生時に、インターネット接続をチェックします。
　インターネット接続が確認できるまで、①の 【↓】曲名.mp4 が表示され続けます。
　タイムアウトは１分です。１分を過ぎると、BEEP音を鳴らし、あきらめて先に進みます。

- 再度プチリリ連携を行う場合、プレイリストから、①の 【↓】曲名.mp4 をクリックして再生してください。
　(②　曲名.mp4 をクリックしてもプチリリは起動されません)

- もちから起動時に、『プチリリ PC版』がインストールされている場合、Windows Media Playerを起動し、
　プチリリの画面表示位置の設定を促すプロンプトが表示されます。
　画面表示の位置設定が終わったら、もちから起動のコマンドプロンプト画面で何かキーを押して下さい。
　一旦プチリリとWindows Media Playerを終了します。

- プチリリ連携時の音はWindows Media Playerで鳴っているので、そのときの音量調整、再生位置調整などは
　MPC-HC側で行っても無意味です。Windows Media Player側で操作を行って下さい。
　ただし、もちからWeb画面での音量調整ボタン(画面上部に [音量▲] [音量▼] と表示されているもの)は
　マスタボリュームに対して調整をしますので、Windows Media Playerの再生に対しても有効です。

- デュアルモニタが割と必須です。(クローンディスプレイ表示は不可)
　シングルモニタもしくはクローンディスプレイで運営した場合、プチリリ連携の曲登録時に、
　Windows Media Playerがウィンドウのフォーカスを奪いやがるので、

　①ファイル名の [ ] で括られた文字列
　②上記がない場合、ファイル名の先頭から、全/半角スペース もしくは"「 "までの文字列

- mp3 ID3tag情報を画面上部に表示
　表示項目
　①タイトル
　②アーティスト名
　③アルバム名
　④タグ付けした人（タイムタグ付txtファイルの@定義から）

- mp3 ID3tag ID3v1 / ID3v2 / @定義(txt) に対応
　ID3tagは文字コードUTF8とSJIS(CP932)に対応
　表示するID3タグの優先順位；
　①タイムタグ付txtファイルの@定義
　②上記がない場合、mp3ファイルのID3v2タグ
　③上記もない場合、mp3ファイルのID3v1タグ
　（表示項目ごとに判定しているため、上記①～③のmp3tagが混在して表示される場合もある）

- mp3 背景動画再生時間の指定を可能に
　右向き三角：背景動画を先頭から使用
　三点　　　：背景動画を真ん中くらいから使用
　左向き三角：背景動画を末尾を使用

### v0.3 mp3対応版
- ディレクトリ階層の大幅変更
- mp3に対応　タイムタグ付txtファイルからassを（自力で）自動生成
- mp3 バッチ起動要
- mp3 htdocs配下の背景動画一覧から動画を選択するように

- mp3 動画生成のシーケンス
　①(オンライン) タグ付テキストファイルからassを生成
　②(バッチ) ffmpegでmp3のDurationを取得
　③(バッチ) mp4boxで背景動画を上記Duration分に切断(-split-chunk)
　④(バッチ) 切断した背景動画から、最初のストリームを抽出し、新規mp4に梱包し直す
　　　　　　(mp4のDurationを設定する(動画再生時のシークバーを適切に表示する)ため

- mp3 背景動画の条件
　以下のファイルじゃないと動かない(バッチが正常に動作しない)。
　①mp4
　②ビデオサイズ 1024 x 576 (16:9) 
　③h264 でのエンコード
　④raw1に動画が格納されていること
　⑤30fps (29.97でも大丈夫と思う…)
　⑥動画より曲の方が長いと変換に失敗するので、動画の長さは10分は欲しい
